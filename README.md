Менеджер задач
Простое и эффективное приложение для управления задачами с системой уведомлений о дедлай
Основные возможности 

### Управление задачами
- #### Создание задач с указанием названия, описания, даты дедлайна и времени напоминания
- ####	Редактирование существующих задач - изменение всех параметров
- ####	Отметка выполнения задач с визуальным отображением зачёркиванием текста
- #### Удаление задач с подтверждением действия
- ####	Фильтрация задач по различным категориям:
-	Все задачи
-	Активные (невыполненные)
-	Выполненные
-	Просроченные
-	Задачи на сегодня
-	Задачи на завтра
###	Поиск по названию задач для быстрого доступа

### Система уведомлений
- #### Автоматические напоминания в системном трее
- ####	Настройка времени уведомлений для каждой задачи индивидуально
- ####	Три типа уведомлений:
1.	Напоминание в день дедлайна в указанное время
2.	Предупреждение о просроченных задачах
3.	Уведомление о задачах на следующий день (в 9:00 утра)
